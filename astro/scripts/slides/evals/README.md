# Behavioral evaluation

See the playbook's EVAL.md. The configured trial count is an evaluation sample
budget, not a catalog/subject limit. The case writer and judge are independent of
the implementer. Baseline and candidate workers get the same brief in isolated
workspaces. The judge sees shuffled labels and actual artifacts without preferred
verdicts. Preserve failures, blocked cases, exact revisions and uncertainty.

Run deterministic `slides:extension` separately; it demonstrates technical
extensibility, not LLM creativity or skill compliance. Asset reviews establish
which icon proof was examined; these paired trials assess the authoring process.

A run report records: case/prompt, variant, workspace revision, actor, supplied
context hashes, actual artifacts, controller-executed checks and exit codes,
reported loaded files, independent judgments and unknown measurements. Supplied
context does not prove it was read. An actor string is not authentication.

The report collector rejects an evaluation marked complete without paired cases,
distinct workers, independent judging and preserved artifact/evidence hashes.
Pending independent runs remain pending. Vault intake and adoption are separate.
