# Vary a room while preserving its purpose

The 9 November 2026 request requires variation within a theme, with the table as
its centre. The existing tabletop-room rules still own scale, supports, collision,
camera, ceilings and functional programs.

1. Preserve the existing seed stream for theme and tabletop placement; append the
   palette, layout, furniture-design and lighting draws. Never randomize a frame.
2. Choose four coordinated palette records per theme using existing room tokens.
   Assign semantic roles rather than independently random colours. Clinical work
   surfaces remain neutral; domestic textiles, timber and accents may vary more.
3. Select real construction variants: chair backs, seat form, sofa cushions, side
   table shape, cabinet fronts/drawers and the table's modesty panel/cross braces.
   Preserve envelopes where practical and measure the final model in every case.
4. Arrange functional zones, not arbitrary positions. This version supports the
   canonical plan, a complete architectural mirror and a deeper secondary-zone
   arrangement. Mirror windows, doors, furniture and mounted light sources together;
   keep the primary table and its inventory anchored. The number of layouts is
   deliberately finite, not unconstrained continuous placement.
5. Move kitchen extraction and cooking surfaces together. Keep shared anchors for
   floor lamps, curtains, fixtures, rugs and storage. A support textile does not
   excuse overlap between separate rugs or between furniture pieces.
6. Key geometry caches by theme, room construction, layout and furniture design.
   Palette/light changes share geometry safely but must reach the main scene,
   frozen previews and both rendering paths. Reversing a mirrored face's winding
   preserves its normal and shadow direction.
7. Sweep all 9 × 3 × 3 × 3 = 243 construction/layout/design combinations. Check
   bounds, disjoint fittings, door approach, connected walking routes, supports and
   camera projection. Then sweep public seed URLs for replay and palette diversity.
8. Compare same-theme seeds in colour and monochrome, including phone and eye view.
   Check that different palettes actually render differently and that switching
   appearance twice restores the image without changing geometry or camera.

Reject random RGB paint, a generic chair in every theme, a moved light left behind
its fixture, cache reuse across different furniture designs, a drawer handle placed
between drawers, or a larger object squeezed into an unmeasured old clearance.
