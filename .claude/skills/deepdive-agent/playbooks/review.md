# Read the evidence

1. Run `npm run deepdive:agent -- review --url=http://127.0.0.1:4321` with the local
   server running. It generates evidence; it does not approve the pictures.
   The browser command can also start its own server on port 4398 and chooses a
   stratified city/all-eras public-seed set by default. The gallery's `--salts` is an
   isolated plan-salt list; the deterministic check's `--seeds` is a case count.
   `deepdive:agent review --salts=...` forwards that list only to the gallery.
2. Inspect the atlas, close-ups and browser captures. Check every scale; include
   both chains, every era, awkward seeds, phone width and reduced motion.
3. Scrub or compare frames immediately before and after a level boundary. Follow a
   particular line/door/street through the opening; watch for clipping and flashes.
4. Answer `LOOK.md` with paths and exact inputs. Compare the reported seed before
   and after, including the unchanged surroundings where practical.
5. If a visual fault repeats, promote its geometric cause into a measured contract
   with a broken fixture. Keep perception-only questions as review cases.
6. Repair the owning stage, then regenerate evidence after the final edit. Record
   the remaining limits without inventing a perfect score.

**Reject:** “looks good” without opened images, judging only the overview, or treating
pixel difference as a quality score.
