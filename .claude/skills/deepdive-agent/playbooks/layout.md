# Plan before marks

**Use when:** changing a domain generator or its randomization.
**Inputs:** seed/grammar inputs, reference decision and acceptance cases.
**Output:** explicit model consumed by the drawing adapter.

1. Set the physical envelope and intentional selected part. Select before placement;
   the portal must not become an arbitrary crop after components are drawn.
2. Reserve primary structure: I/O/pad ring and routing channels; streets and water;
   or shell, circulation, service core and entrances.
3. Fit repeated units into those reservations using pitch and containment constraints.
   Randomize a valid family, count or proportion rather than each detail independently.
4. Add declared terminals, frontages, door openings or contour field values. Keep
   related detail attached to the same owning entity.
5. Draw from that model. Add fine detail only where the parent unit has room for it.
   A failed placement is an explicit omission or a failed plan, never hidden geometry.
6. Compare bounds, adjacency, repetition and useful variation over the seed sweep.

**Reject:** scattered rectangles connected afterward, independent adjacent contours,
negative-size furniture or compartments silently clipped to fit.
