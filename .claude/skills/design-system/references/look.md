# Looking at a token change

A check measures a ratio. It cannot tell you whether the page still looks like the notepad. Answer these with the
page open, in both themes, before you hand over.

1. **Is it the same notepad?** Day is cream paper, night is gunmetal paper, with the same strip, margin line and
   tear. A change that makes night look like a different design is wrong (R-COL-7).
2. **Is there one orange?** Every orange you see is the signal (`--pp-signal`) or, for small text, the text orange
   (`--pp-signal-text`). A second, muted orange reads as a mistake (R-COL-2).
3. **Is orange still rare?** It marks the one thing to look at. If the change spends it on a band, a block or every
   heading, the page has lost its focus (R-COL-1).
4. **Can the quietest text be read?** Comments, captions and labels, not only the body. Read them at arm's length.
5. **Did a figure change?** Figures are recoloured from the tokens. Open a page with a cover and compare it with
   the figure bench (`/figures`): the strokes should still be clear against the paper.
6. **Does the ledger show it?** The token or component appears on `/design-system/` with the same value the page
   uses.

If an answer is no, fix the token, not the page around it.
