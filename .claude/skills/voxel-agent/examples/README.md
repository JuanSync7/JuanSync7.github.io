# Examples and evidence

`prompt.md` is the reusable request shape. Runtime evidence is generated under
`astro/figures-out/`: `voxel-agent-report.json` holds the seed cohort and diversity
measurements, `voxel-scene.seeds.png` holds numbered compositions, and browser captures
show every biome and the phone/fallback/drag views. These files are evidence from a
run, not a permanent declaration that every later revision looks good.

The preserved repetition case is the preceding generator: it always placed a cottage
and aimed for two boats. The negative diversity fixtures reject that output shape.
The access regression is a later building reaching an earlier tent's unreserved
entrance. The placement stage now reserves access immediately; keep that case in the
balanced seed matrix rather than moving one tent by hand.
