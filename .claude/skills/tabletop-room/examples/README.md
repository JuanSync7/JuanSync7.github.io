# Room examples

The negative case is the user's 7 November 2026 proportion correction. Its geometry
is captured in `astro/scripts/figures/room-proportion-before.json`: the dining table
occupied 43.3% of the room floor even though the prior pixel audit had passed.
The source revision is preserved in that fixture.

Current colour and monochrome sheets are generated by `npm run rooms:verify` under
`astro/figures-out/`. The handoff and vault feedback package preserve the exact
reviewed images and validation revision. Treat these as agent-reviewed candidates;
human acceptance of the new room design has not yet been observed.

The existing metre-scale plan vocabulary in `kit/furniture.ts` is a useful plain
reference: distinct furniture sizes, seats around a table, sink/cooking runs, storage
and an entrance path. The vault's figure example for floor plans records the user's
specific door-clearance correction. See the reference card in the room treatment.
