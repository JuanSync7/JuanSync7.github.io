# Evaluation evidence

Two lanes have separate conclusions:

- Deterministic output and extensibility checks: executable geometry/source,
  schema, ownership, import freshness, archive and native SVG checks.
- Behavioral authoring evaluation: fresh paired baseline/candidate sessions and
  independent visual/fit judgment. This lane is not inferred from asset tests.

The baseline is the published authoring package at `263c31e`. The candidate
introduces progressive stage loading, declared constraints and an open catalog.
Compare the package as a whole; this does not isolate one instruction's effect.
The candidate was drafted before the paired baseline replay, so the comparison
is retrospective. Existing user corrections supplied the initial failure signal.

Independent trials require the host's explicit delegation authorization. Until
those runs occur and evidence is checked, `evaluation.json` stays pending.
A completed report must preserve failures and limits; counts are not proof of
universal creativity. Vault proposal/review/release registration and later-use
measurement remain separate from this repository's evaluation.
