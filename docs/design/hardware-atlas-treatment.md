# Hardware atlas treatment

The atlas explains physical assemblies through coherent isometric solids,
wireframes, an exploded pose and inspection of named parts. Both compute dies,
every memory stack and other repeated pieces belong to their semantic assembly.
The seeded strip remains a collection of still previews; the main viewer is live.

## Acceptance

Traces stay on their support and terminate at real source and sink footprints.
Independent conductors use separate Manhattan lanes. Surface details follow the
same transform as their host; filled mesh faces do not expose construction seams.
Every selected repeated solid receives a restrained accent, behind nearer opaque
faces. Camera changes, inspection and isolation keep the object framed. SVG and
canvas use the same projected geometry. Eight idle previews do no ongoing frame
work, and choosing one retains interaction in the main viewer.

The executable acceptance map is
[the playbook checks](../../.claude/skills/hardware-atlas/checks/README.md).
Physical plausibility and visible occlusion remain explicit visual judgments.

## Revision record

| User observation | Confirmed cause | Repair and proof |
|---|---|---|
| Wires leave bounds or look awkward. | Independent board/interposer routes share lanes; server laminate uses origin-centred coordinates on a translated board. | Separate conductors, align markings with the board; support, lane, endpoint and laminate regressions. |
| Scrolling the seeded strip is laggy; static collection is fine. | All eight visible seed canvases continually repaint. | Freeze previews and skip unseen warm-up work; normal-motion idle profile plus live main-view test. |
| Repeated parts have only one accent. | Signal selection chooses one face across an entire semantic assembly. | Preserve solid identity and choose an accent per solid, retaining painter order; missing-copy negative fixture. |
| Isometric/wireframe glitches need a repeatable pipeline. | Hollow rim tessellation is outlined and rear markings paint through their own wall; mechanical and visual checks cover different properties. | Suppress internal rim seams, retain boundary rings, clip same-solid hidden strokes; kernel index, deterministic checks and required visual review. |

## Limits and choices

These are schematic icons, not dimensionally exact models or electrical designs.
Support containment samples declared trace segments; decorative wires, flex fingers,
general mesh intersections and every possible occlusion are not exhaustively proved.
Inspect those in the browser. Still previews preserve all eight seeds; reducing
the collection to one object is unnecessary once idle frame work is removed.
No new runtime dependency or general figure-audit threshold is needed.
